Hey there! This document will be used to share how DragonVale World Revival progress is going. Initially, we can know that I have gotten to know how login works. For now the app still hasn't loaded to tutorial despite repeated attempts to load it via mock servers that emulate the app login process. I have gotten the fair share of assets from an APK, but I'm currently working on the IPA given that it's much easier for my workflow, and it also reports logging when the app crashes unlike a regular APK. The app will be released for both iOS and Android. Currently confirmed IPA connects to certain CloudFlare/CloudFront addresses after redirection from original server link. The iOS version of DVW (v1.26) will be compatible from iOS 9+, though I have yet to test on a phone. It'll also be 64-bit. The Android version will be compatible from Android 4.4 (KitKat) and over. There is a catch. Until further modification work is done in the future, the app will only support 32 bit compatible devices. All questions about the game will be answered on the issues category. We also have acquired 407 assets in total from the APK which include characters, PFPs, soundtracks used…  which I will attempt to use in the final game. I'm currently attempting to binary remove the in-app restriction for iOSGodsCom.dylib for DVW. Unfortunately, DVW contains embedded anti-tamper checks which difficult doing this. Ultimately everything is fixed except for the fact that the server address to which it connects to is hardcoded. Without an online server we need to get the assets that aren't present elsewhere. We've removed the iOSGods restriction from the app. Next we must create a mock server that is exactly if not almost the same for DVW to work correctly. We have managed to make a file which logs full app progress so we can directly view and make mock servers easier for DVW.  Old archives of the game server have been found on the Wayback Machine. I have found that the game connects via QUIC (HTTPS3) protocols. Overmind.json has been found to be the file that decides to what address DVW connects to. It is protected by a 32 byte header with integrity validation. To modify it it must be patched. To connect to an external server we will use to run the full game, we will modify overmind.json appropriately and attempt to see whether it is modifiable by standard methods.
